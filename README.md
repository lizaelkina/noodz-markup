### Описание проекта

- Одностраничный, адаптивный сайт на Flexbox и Grid Layout.
- Бегущая строка и другие анимации сайта выполнены с помощью CSS-анимации.
- Кастомный видеоплеер с отложенной загрузкой и режимом закрепления (Sticky / Picture-in-Picture) при скролле на базе
  Intersection Observer API.
- Форма обратной связи с кастомной обработкой состояний и анимированным уведомлением об отправке.
- Пасхалка: наведите курсор на смайлик (на телефоне — коснитесь), и он вас подразнит.
